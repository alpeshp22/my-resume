## Updating the resume

1. Edit the content in `index.html`.
2. Regenerate the PDF so it matches the web page:
   - Open `index.html` in Chrome and press `Ctrl + P`.
   - Destination: **Save as PDF**. Under *More settings*, turn off **Headers and footers**.
   - Save as `Alpesh_Parmar_Resume.pdf` in this folder, replacing the old file.
3. Commit and push. GitHub Pages updates the live site within a minute or two.
